DevelopmentALL Backup

DevelopmentALL Backup is a personal backup tool operated by an individual for private use.

It uses rclone and restic to copy the owner's own files from a home computer to the owner's own Google Drive, so the files can be restored if the computer fails.

The tool is not a public service. It is not offered to other users, and no one else can sign in to it.
